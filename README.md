# DHANANJAY Classes – Handwriting Improvement Classes Website

Official modern, responsive, and high-converting single-page website for **DHANANJAY Classes** (Jalgaon, Maharashtra), specializing in handwriting improvement in **Marathi (मराठी), Hindi (हिंदी), English Print, and English Cursive**.

---

## 🌟 Key Features of the Website

- **Brand Identity & Theme Matching:** Uses the official colors (Deep Navy `#0B1325`, Brand Red `#DC2626`, Golden Amber `#F59E0B`, Clean White) matching the class logo and flyers.
- **Bilingual Support (English & मराठी):** One-click language switcher (`EN` / `मराठी`) translates headings, badges, descriptions, and forms across the website.
- **Live Branch Operating Status:** Calculates live Indian Standard Time (IST) and displays whether the branch is currently **Open** or **Closed** with operating shifts.
- **Before & After Transformation Gallery:** Filterable showcase for Marathi, Hindi, English Cursive, and English Print with interactive full-screen Lightbox zoom.
- **1-Click WhatsApp Lead Generator:** When visitors fill the quick 30-second inquiry form, it automatically crafts a structured lead message and opens WhatsApp directly to Dhananjay Sir (`+91 7709501331`).
- **Direct Navigation & Call Integration:** Click-to-call buttons and direct link to the [Google Location Pin](https://share.google/KFDQzlEBSiFO2rSrW).
- **Sticky Mobile Action Bar:** Fixed bottom bar for smartphone visitors with quick thumb buttons for Call, WhatsApp, Location, and Enroll.
- **Lightning-Fast & Ultra-Lightweight:** Pure HTML5, Tailwind CSS, Lucide icons, and modern JavaScript — zero heavy build step required, loads instantly even on 3G/4G connections.

## 🚀 How to Preview Locally

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to open it directly in Google Chrome, Microsoft Edge, or any browser.

### Option 2: Local Python Server (Recommended)
Open a terminal in this directory and run:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.

## 🌐 100% Free Live Hosting Options

You can host this website online completely free of cost with a live `https://` link:

### 1. Netlify Drop (Easiest — 30 Seconds, No Coding Needed)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire project folder (`Dhananjay-Handwriting`) into the browser window.
3. Your website goes live immediately with a free SSL link like `https://dhananjay-classes.netlify.app`.

### 2. Vercel (1-Click Deployment)
1. Install Vercel CLI via terminal: `npm i -g vercel` or upload to GitHub.
2. Run `vercel` in this folder.
3. Your website gets a fast global CDN link like `https://dhananjay-classes.vercel.app`.

### 3. GitHub Pages (Free Permanent Hosting)
1. Initialize git and push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Dhananjay Classes website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. In GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In 1 minute, your website is live at `https://<your-username>.github.io/<repo-name>/`.
